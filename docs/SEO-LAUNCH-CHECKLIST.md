# SEO and domain launch checklist

The repository includes the technical foundations, but search ranking is not instant or guaranteed.

## Before deployment

- Replace placeholder email and GitHub URLs.
- Confirm each page has one H1 and unique title/description.
- Keep the visible product description consistent with JSON-LD.
- Confirm canonical URLs use `https://ninai.io`.
- Confirm the logo and Open Graph image are publicly reachable.
- Test every internal link.

## After deployment

1. Verify both the apex domain and `www` DNS configuration.
2. Enforce HTTPS.
3. Open and verify:
   - `https://ninai.io/robots.txt`
   - `https://ninai.io/sitemap.xml`
   - `https://ninai.io/.well-known/security.txt`
4. Create a Google Search Console domain property.
5. Submit `https://ninai.io/sitemap.xml`.
6. Use URL Inspection for the homepage and request indexing.
7. Validate the homepage using Google's Rich Results Test.
8. Add the website URL and product description to the GitHub repository metadata.
9. Link to `ninai.io` from your LinkedIn profile and launch posts.
10. Publish useful, original research pages rather than thin keyword pages.

## Target terms used naturally on the site

- user-owned AI memory
- local-first AI memory
- MCP memory server
- Claude Code memory
- permissioned AI context
- AI context firewall

Do not stuff keywords or create fake comparison pages.
