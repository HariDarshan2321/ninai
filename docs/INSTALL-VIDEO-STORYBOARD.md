# Ninai installation video

Target length: 60 to 90 seconds. Produce separate Mac and Windows recordings
after both signed installers exist. The current local preview video explains the
flow without claiming that the Windows package is generally available.

## Storyboard

1. **Problem**: Work completed in one assistant should remain available when the
   user opens another assistant.
2. **Download**: Choose Mac or Windows. Show Windows as preview until the signed
   package passes its release gate.
3. **Install**: Open the installer. The final release must not require Terminal,
   Python, Homebrew, PowerShell, or administrator access.
4. **Connect**: Ninai shows detected assistants. The user chooses which ones to
   connect.
5. **Control**: The user chooses which memory areas each assistant may use.
6. **First test**: Save one project decision and recall it from a second
   assistant with its source attached.
7. **Revoke**: Turn access off and show that the next request is denied.
8. **Close**: The complete memory remains on the user's computer.

Use captions throughout, enlarge the cursor during clicks, avoid MCP and database
terminology, and never show real user memory or account information.
