# Ninai Brand System

## Core Idea

Ninai gives AI a useful memory without giving it a free pass.

The brand should make one product truth immediately visible: the complete vault stays
with the person, while a deliberately small opening releases only permitted context.

## Signature

The Ninai mark is called **The Return**. Its incomplete circular path and central point
represent useful context returning across sessions without exposing everything around it.

The website extends that mark into the **context aperture**: a small, controlled window
through which selected memory can pass. The aperture is Ninai's repeatable visual behavior.

Avoid generic AI imagery: neural networks, glowing brains, purple gradients, star fields,
glass cards, floating orbs, and unexplained magic.

## Promise

> Your AI should remember the work. Not your whole life.

Supporting proof:

- useful decisions and commitments survive the session;
- existing Linear, GitHub, and MCP connections stay where they are;
- the complete memory vault remains local;
- every released fact has a source;
- access can be revoked by scope.

## Personality

- **Calm:** Ninai reduces anxiety rather than manufacturing urgency.
- **Exact:** Say what the MVP does and name what it does not do yet.
- **Human:** Lead with continuity, commitments, and control before infrastructure.
- **Quietly technical:** Let the evidence, source, packet, and permission model prove depth.
- **Independent:** Ninai serves the person across AI providers.

## Voice

Prefer short, declarative sentences with concrete nouns and verbs.

Use:

- “Keep your tools where they are.”
- “The vault stays. The packet travels.”
- “Two facts returned. Thirty-five stayed private.”
- “Revoke the scope. The memory stays put.”

Avoid:

- “Unlock the power of AI.”
- “Revolutionary second brain.”
- “Seamless, magical, intelligent memory.”
- claims of academic novelty, complete security, or universal client support.

## Personas

### Builder

Needs architecture decisions, project state, and tool outcomes to survive a fresh session
without reconnecting existing developer tools.

### Operator

Needs commitments, ownership, deadlines, and follow-ups to remain visible across context
switches.

### Steward

Needs to know what each AI received, why it received it, and how to revoke future access.

## Color

The palette comes from the product boundary rather than the AI category.

| Token | Value | Meaning |
|---|---|---|
| Vault | `#0B302B` | Local storage, calm control, trust |
| Paper | `#F4EFE5` | Human work, clarity, an owned record |
| Signal | `#FF6846` | A durable outcome returning to attention |
| Permit | `#DCEF7B` | Explicitly allowed context |
| Ink | `#111512` | Precision and high-contrast typography |
| Moss | `#9CB5A8` | Secondary system information |

Use Vault and Paper for most of the surface. Signal should mark key actions and returning
memory. Permit is reserved for access state, not decorative highlighting.

## Typography

- The custom Ninai wordmark remains the primary brand signature.
- Human-facing display language uses a high-contrast editorial serif.
- Product explanation and controls use a humanist sans-serif.
- Evidence, scopes, sources, and packet details use monospace.

This creates a deliberate contrast between human memory and machine policy without adding
a remote font dependency to the local-first MVP.

## Layout and Motion

- Use generous empty space around one decisive message.
- Prefer one strong product explanation over several decorative cards.
- Use asymmetry to distinguish human explanation from system evidence.
- Let the aperture open, close, and return; avoid ambient motion with no meaning.
- Respect reduced-motion preferences.

## Brand lock

The following elements are stable brand assets, not page-level implementation
details. Product-status or copy updates must preserve them unless the founder
explicitly approves a brand redesign:

- the Vault, Paper, Signal, Permit, Ink, and Moss palette and their meanings;
- The Return wordmark and app icon;
- the interactive context aperture as the homepage's signature product visual;
- the editorial serif, humanist sans, and evidence-monospace hierarchy;
- the calm, asymmetric, evidence-led homepage composition;
- Signal for calls to action and returning memory, and Permit only for allowed state.

Before merging a website change, compare the rendered homepage with the latest
approved production reference at desktop and mobile widths. Updating product
truth, compatibility, or calls to action does not authorize replacing the
visual system with a generic landing-page theme or decorative card grid.
